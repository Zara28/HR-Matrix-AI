# HR Matrix CLI: Автоматизированный пайплайн сбора и оценки вакансий

Консольная утилита для автоматического сбора IT-вакансий (C# / .NET), извлечения компетенций с помощью LLM (Saiga) и расчета Индекса топологической зрелости (TSI) на основе алгоритмов машинного обучения.

## 📂 Структура проекта

```text
hr_matrix_cli/
├── data/
│   ├── raw/                  # Сырые данные после парсинга
│   ├── processed/            # Очищенные данные и датасеты после LLM <---SKILL_IMPORTANCE_MATRIX.csv лежит тут, это эталон для работы клиента
│   └── final/                # Итоговые результаты с кластерами
├── scrapers/                 
│   ├── parser_sites.py       # Сбор вакансий (Habr Career, Remote-Job)
│   └── parser_telegram.py    # Сбор постов из Telegram-каналов
├── nlp/                      
│   └── llm_dataset.py        # Обработка текста и NER-разметка через akdengi/saiga-llama3-8b
├── analytics/                
│   └── clustering_tsi.py     # Расчет TSI, KMeans-кластеризация и поиск порогов
├── config.py                 # Глобальные настройки путей и параметров
├── main.py                   # Главный скрипт-оркестратор
└── README.md                 # Документация проекта

```

## 🛠 Установка и настройка

**1. Установка Python-зависимостей**
Убедитесь, что установлен Python 3.9+, и выполните команду:

```bash
pip install pandas scikit-learn telethon playwright python-dotenv ollama qrcode

```

**2. Настройка браузера для парсинга сайтов**
Для работы модуля Playwright (сбор данных с веб-страниц) необходимо установить бинарные файлы браузеров:

```bash
python -m playwright install

```

**3. Настройка локальной LLM (Ollama)**
Пайплайн использует локальную модель `saiga` для безопасного и бесплатного извлечения сущностей (NER).
Убедитесь, что Ollama запущена на вашем ПК, и скачайте модель:

```bash
ollama pull akdengi/saiga-llama3-8b
```

**4. Настройка Telegram API**
Для парсинга Telegram-каналов требуется авторизация.

1. Получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org).
2. Создайте файл `.env` в корне проекта (рядом с `main.py`).
3. Добавьте в него ваши ключи:

```env
TG_API_ID=ваш_id
TG_API_HASH=ваш_hash

```

## 🚀 Запуск пайплайна

Для запуска полного цикла сбора и аналитики выполните:

```bash
python main.py

```

### Важные нюансы при первом запуске:

* **Авторизация Telegram:** При самом первом запуске в консоли появится QR-код. Отсканируйте его через мобильное приложение Telegram (Настройки -> Устройства -> Подключить устройство). Если включена 2FA, консоль запросит облачный пароль. После успешного входа создастся файл `parser_session.session`, и дальнейшие запуски будут происходить полностью автономно.
* В случае ошибки `auth token expired` в Telegram, просто удалите файл `parser_session.session` и перезапустите скрипт для обновления авторизации.

## 📊 Этапы работы (`main.py`)

1. **Сбор данных:** Параллельный опрос IT-порталов (через headless-браузер) и профильных Telegram-каналов (через Telethon API). Результаты сохраняются в папку `data/raw/`.
2. **NLP-анализ:** Очистка от дубликатов, строгая фильтрация по стеку (C# / .NET) и передача текстов в Saiga LLM. Модель возвращает структурированный JSON с требуемым опытом, технологическим стеком и архитектурными паттернами.
3. **Аналитика (TSI & KMeans):**
* Скрипт сопоставляет извлеченные навыки со статичным эталонным справочником `SKILL_IMPORTANCE_MATRIX.csv`.
* Высчитывается показатель WSP (Weighted Stack Power) и итоговый **TSI**.
* Алгоритм `KMeans` разбивает кандидатов на 3 кластера (Junior, Middle, Senior).
* Вычисляются математические границы грейдов на текущем срезе рынка.



**Итоговый результат** выводится напрямую в консоль (в виде значений порогов) и сохраняется в файл `data/final/FINAL_CLUSTERED_RESULTS.csv` для использования в бэкенд-архитектуре.
