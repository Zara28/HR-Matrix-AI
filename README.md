# HR Matrix AI 

Интеллектуальная система автоматизированной оценки кандидатов на IT-позиции. Прототип HR-платформы, которая сопоставляет результаты технических опросников (из Google Таблиц) с рыночными требованиями и оценивает качество кода кандидата с помощью векторного анализа.

---

##  Ключевые возможности

*   **Синхронизация с Google Таблицами:** Импорт ответов кандидатов из опросников в реальном времени.
*   **Векторный анализ кода (K-score):** Сравнение кода кандидата с эталонными (`ideal`) и антипаттернными (`broken`) кодовыми базами для конкретной вакансии с использованием языковых моделей и косинусного сходства.
*   **Динамические пороги TSI (Technical Skill Index):** Автоматическое определение и настройка границ грейдов (Junior / Middle / Senior).
*   **Матрица компетенций:** Загрузка и управление весами навыков через Excel/CSV файлы.
*   **Встроенная утилита расчета:** Модуль для автоматического расчета дрейфующих порогов TSI и генерации матриц.
*   **Современный интерфейс:** Легкий и эргономичный UI в пастельной корпоративной гамме (Vue 3, Vite, PrimeVue).

---

## Архитектура проекта

Проект организован в виде монорепозитория, объединяющего бэкенд, фронтенд и внутренние утилиты расчета:

```text
hr-matrix-ai/
├── backend/                  # FastAPI сервер и бизнес-логика
│   ├── core/                 # Настройки базы данных (SQLite) и модели SQLAlchemy
│   ├── ml/                   # ML-модуль анализа кода и эмбеддингов
│   ├── routers/              # API-эндпоинты (кандидаты, настройки, вакансии)
│   ├── services/             # Процессоры обработки опросников и расчетчиков TSI
│   └── utils/                # Внутренние утилиты для расчета порогов и матриц
├── src/                      # Frontend (Vue 3 + Vite)
│   ├── views/                # Страницы (Дашборд, Профиль кандидата, Настройки)
│   └── App.vue               # Корневой компонент интерфейса
└── README.md

```

---

##  Технологический стек

* **Frontend:** Vue 3 (Composition API), Vite, PrimeVue, Chart.js.
* **Backend:** Python, FastAPI, SQLAlchemy, Pydantic.
* **Data & ML:** Pandas, Sentence-Transformers (векторизация кода), SQLite.

##  Инструкция по запуску

### 1. Запуск Бэкенда

Перейди в папку бэкенда, установи зависимости и запустить сервер:

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

```

*Сервер запустится по адресу: `http://localhost:8000*`

### 2. Запуск Фронтенда

В отдельном терминале перейди в корневую папку проекта (где лежит `package.json`), установи пакеты и запусти клиент:

```bash
npm install
npm run dev

```

*Интерфейс будет доступен по адресу: `http://localhost:5173*`

## 💡 Использование

1. Зайдите в **«Настройки»**, добавьте вакансию, указав ссылку на Google Таблицу с ответами, а также эталонный и сломанный код для оценки `K-score`.
2. Настройте пороги TSI под требования компании.
3. Вернитесь на **«Сводку»**, выберите нужную вакансию и нажмите кнопку **«Синхронизировать»** для подтягивания и анализа кандидатов.
